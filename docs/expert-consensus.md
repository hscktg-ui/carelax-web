## 2. 업계 공통 성공 패턴 (합의)

1. **브랜드와 구매 채널 분리** — 사이트는 믿음을 팔고, 몰/스토어는 결제를 담당 (세라젬  clearest).
2. **자체 기술 언어** — 스펙 나열이 아니라 브랜드만의 케어 이름 (xxx-TECH / ROVO / 4D 등).
3. **라이프스타일·인테리어 프레이밍** — “기계”가 아니라 거실에 사는 가구·회복 공간.
4. **플래그십 먼저, 라인업은 니즈별** — 전 모델 평등 그리드보다 시그니처 1 → 용도별 분류.
5. **신뢰는 짧게** — A/S·상담·구매 경로만 분명히 (코지마 3가치 구조가 효율적).
6. **첫 뷰포트 절제** — 브랜드명 + 한 약속 + CTA 1~2개. 라이브·쿠폰·배너 클러스터 금지.

## 3. 케어렉스 포지셔닝 (50인 회의 결론)

> **Accessible Quiet Recovery**  
> 거대 브랜드의 기술 스펙터클과 할인 몰 사이에,  
> **부드러운 안마볼 케어 · 국내 주거에 맞는 스케일 · 스마트스토어로 단순한 구매**를 제시한다.

| 축 | 거대 브랜드 | 케어렉스 |
|----|-------------|---------|
| 메시지 | 의료·특허·No.1·4D/ROVO | 짧게 깊게 회복, Soft Care |
| 공간 | 풀사이즈·쇼룸 중심 | Compact~Full, 집 규모 맞춤 |
| 구매 | 자사몰·할부·라이브·매장 | 스마트스토어 주력 1경로 |
| 톤 | 하이테크 / 프로모션 | Quiet luxury · 가구형 휴식 |

**따라하지 않을 것**  
바디프랜드식 라이브·기획전 과밀, 세라젬식 의료 클레임, 코지마식 인증 벽 나열, 비렉스식 대기업 서브브랜드 의존.

**가져올 것**  
세라젬의 철학·TECH 네이밍·채널 분리 / 코지마의 헬스테리어·A/S 신뢰 / 바디프랜드 EN의 Aesthetic+케어·플래그십 서사 / 비렉스의 공간·다기능 가구 인식.

## 4. 확정 IA (홈 스크롤)

1. **Hero** — CARELAX + 한 문장 약속 + 구매 / 철학  
2. **Position** — 왜 케어렉스인가 (시장 속 좌표, 경쟁사명 노출 최소화)  
3. **Philosophy** — Care / Relax / Recover  
4. **Method** — Ball Care · Soft Mode · Space Fit (자체 언어)  
5. **Signature** — 주력 상품 딥다이브 → Smart Store  
6. **Lineup by need** — 가족 소프트 / 스마트 / 공간 / 비즈니스  
7. **Trust** — 구매·A/S·운영시간  
8. **Final CTA** — 스마트스토어만

## 5. 카피·디자인 가이드라인

- 첫 뷰포트: 브랜드가 히어로. 헤드라인이 브랜드를 이기지 않음.
